# 技術雛形（階段五）

樣品教室（符文學教室）＋樣品角色（艾洛拉），用來驗證第一人稱、手機橫直向、魔杖、手機掃 QR code 配對，以及讓製作人判斷美術風格。

不需要 build，整個 `prototype/` 資料夾直接放上網站就能玩（例如 GitHub Pages：`https://hao-yuliu.github.io/Kooomp/prototype/`）。本機測試：在 `prototype/` 裡開一個靜態伺服器（例如 `npx http-server -c-1 .`）。

## 可以試的東西
- **走動**：電腦 WASD＋滑鼠（點畫面鎖定滑鼠）、Shift 跑、E 調查／對話；手機橫向，左半邊搖桿、右半邊滑動轉視角、右下「調查」鈕。
- **手機方向**：一般遊玩強制橫向（Android 全螢幕時真的鎖定，iPhone 蓋提示）；拿出魔杖時強制直向，轉回橫向就收起魔杖。
- **施咒（三種方式都能施同一個咒）**
  | 咒語 | 畫符文 | 揮動手機 | 效果 |
  |---|---|---|---|
  | 光照咒 Lumen | ○ | 揮一下 | 點亮所有燭火 |
  | 顯影咒 Revela | △ | 往前刺 | 黑板浮出血字，接著突然嚇人（燈全滅、黑影出現在面前、肖像畫的臉融化） |
  | 退散咒 Expel | ϟ／Z | 往上舉 | 吹開漂浮的書，肖像畫恢復原狀 |
- **手機當魔杖（加分玩法）**：電腦右上「用手機當魔杖」→ 手機掃 QR code → 手機上揮動或畫符文，電腦畫面施咒。
- **有骨架的角色（月晞、沃恩）**：製作人提供的 Character Creator 免費基本模型（女、男）。原檔只有內衣、沒有皮膚和頭髮貼圖，`src/cc.mjs` 補上：
  - 皮膚：依臉部位置畫出嘴唇、臉頰、鼻頭、耳朵的血色和眼窩陰影，加上毛孔凹凸和邊緣透紅。
  - 頭髮：髮根深、髮尾淡、每撮深淺不同；頭皮在髮際線淡出。
  - 衣服：程式做的學院斗篷（月晞格里莫瓦深紅＋羊皮紙色、沃恩貝爾蒙特黑＋金）。
  - 動作：用骨架把 T 字站姿的手放下、呼吸、轉頭看玩家、眨眼、說話時嘴巴動、微笑和驚恐的表情。
  - 減輕負擔：原本 121 種表情只留 12 種。
- **法杖**：製作人提供的星月法杖（原檔 150 萬個頂點、11 MB），合併相近的頂點減到約 4 萬個三角形、760 KB（`models/staff/staff.glb`），放在第一人稱畫面右下角，施咒時舉起並發出咒語的顏色。
- **同一個模型換色做出不同角色**（舊做法，現在只剩艾洛拉用）：書架旁的**月晞**和窗邊的**艾洛拉**用的是同一個 Female_Human 模型，只換了髮色（月晞黑髮）、領帶學院色（艾洛拉淡藍、月晞深紅）、眼睛顏色（艾洛拉藍眼）、身高。做法在 `src/model.mjs` 的 `look` 參數。臉和髮型會一樣；月晞的台詞是暫定的樣品。
- **角色風格比較**：右上「角色」鈕切換「寫實模型」（製作人提供的 Female_Human）和「程式繪製」（卡通渲染＋手繪風臉，會眨眼、換表情、說話時嘴巴動）。網址加 `?char=code` 預設程式繪製。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css` | 遊戲畫面與介面 |
| `wand.html` | 掃 QR code 打開的魔杖頁 |
| `src/scene.mjs` | 教室（材質全部用程式畫）、燭火、月光、灰塵、驚嚇 |
| `src/character.mjs` | 程式繪製的艾洛拉 |
| `src/model.mjs` | 載入寫實模型（艾洛拉）；模型沒有骨架，用程式把 A 字站姿的手臂放下來 |
| `src/cc.mjs` | 有骨架的角色（月晞、沃恩）：皮膚、頭髮、斗篷、表情、動作 |
| `src/controls.mjs` | 第一人稱操作（鍵鼠、觸控搖桿） |
| `src/orient.mjs` | 手機橫向／直向 |
| `src/spells.mjs` | 咒語、符文辨識（$1 辨識法）、揮動手機的判斷 |
| `src/link.mjs` | 電腦與魔杖手機的連線（Supabase 即時廣播頻道 `ml_wand_配對碼`，不寫資料表） |
| `src/audio.mjs` | 全部即時合成的音效 |
| `vendor/` | three.js 0.169、supabase-js 2.45、qrcode-generator 1.4.4（放在本地，不靠 CDN） |
| `models/female/` | 艾洛拉的模型（FBX）與貼圖（從 .blend 取出、縮成 1024 的 JPG） |
| `models/girl/`、`models/male/` | 月晞、沃恩的 Character Creator 基本模型（FBX） |
| `models/staff/` | 減量後的法杖（GLB） |

## 已知限制
- 在開發環境裡沒有顯示卡、也連不到 Supabase，所以「揮動手機」的靈敏度和「QR code 配對」**還沒在真的手機上測過**，需要製作人實測。
- 寫實模型沒有骨架：不能走路、沒有表情、嘴巴不會動，只會呼吸般微動並轉身面向玩家。要動起來需要綁骨架（例如 Mixamo 自動綁定）。
- 男性模型（Male_Human）的貼圖不在上傳的檔案裡；學士帽（AcademicCap）只有 Unreal／Blender 格式，這次沒有用到。
- 月晞、沃恩的模型很細（各約 15 萬個頂點），三個角色同時在畫面裡，舊手機可能會卡。要再減量的話，最好在 Blender 裡做。
- 斗篷是簡單的形狀，不會隨動作擺動；正式版最好換成真正的制服模型。
