# 技術雛形（階段五）

樣品教室（符文學教室）＋樣品角色（艾洛拉），用來驗證第一人稱、手機橫直向、魔杖、手機掃 QR code 配對，以及讓製作人判斷美術風格。

不需要 build，整個 `prototype/` 資料夾直接放上網站就能玩（例如 GitHub Pages：`https://hao-yuliu.github.io/Kooomp/prototype/`）。本機測試：在 `prototype/` 裡開一個靜態伺服器（例如 `npx http-server -c-1 .`）。

## 可以試的東西
- **走動**：電腦 WASD＋滑鼠（點畫面鎖定滑鼠）、Shift 跑、E 調查／對話；手機橫向，左半邊搖桿、右半邊滑動轉視角、右下「調查」鈕。
- **手機方向**：一般遊玩強制橫向（Android 全螢幕時真的鎖定，iPhone 蓋提示）；拿出魔杖時強制直向，轉回橫向就收起魔杖。
- **施咒（三種方式都能施同一個咒）**
  | 咒語 | 畫符文 | 揮動手機 | 效果 |
  |---|---|---|---|
  | 光照咒 Lumen | ○ | 揮一下 | 點亮所有燭火 |
  | 顯影咒 Revela | △ | 往前刺 | 黑板浮出血字，接著突然嚇人（燈全滅、黑影出現在面前、肖像畫的臉融化） |
  | 退散咒 Expel | ϟ／Z | 往上舉 | 吹開漂浮的書，肖像畫恢復原狀 |
- **手機當魔杖（加分玩法）**：電腦右上「用手機當魔杖」→ 手機掃 QR code → 手機上揮動或畫符文，電腦畫面施咒。
- **角色一覽**：`cast.html`，所有做好的角色站成一排，按「上一位／下一位」或上面的名字切換，「近看臉」看特寫。
- **主角（教室裡都有，走過去可以對話）**
  - 艾洛拉、月晞、沃恩：Character Creator 的免費基本模型（有骨架、有臉部表情）。原檔只有內衣、沒有皮膚貼圖，`src/cc.mjs` 補上皮膚（嘴唇、臉頰、眼窩的顏色、毛孔）、頭髮顏色、學院斗篷，並用骨架放下手臂、呼吸、轉頭看玩家、眨眼、說話時嘴巴動、微笑和驚恐的表情。艾洛拉的模型附眼鏡，預設不戴。
  - 西里爾：「Modern Tarzan」模型，沒有骨架和表情（`src/cyril.mjs`）：移動頂點把手放下、程式畫眼睛和頭髮、穿斗篷；整個人會轉向玩家，但不會眨眼、說話。
- **衣服**（`src/outfit.mjs`、`src/costumes.mjs`）：女生穿 JK 制服（格子裙、領結換學院色），男生穿男生制服，外面都套學院色的長大衣。衣服模型沒有骨架，程式依肩膀、肩寬、骨盆高度對齊到身上，袖子轉到跟手臂一樣，陷進身體的地方往外推，再抄身體最近那個點的骨架設定，所以會跟著呼吸、轉身；被蓋住的皮膚和內層衣服藏起來。素材授權見 `models/CREDITS.md`（JK 制服是 CC BY，要標示作者）。
- **守夜人**：怪物模型「possessed critter」＋製作人用 Mixamo 加的四個動作（待機、走路、跑步、撲抓）（`src/warden.mjs`）。原檔的貼圖沒有附上，每個零件用程式上色；右手提綠燈。顯影咒之後的驚嚇，他會撲向玩家。角色一覽可以按「換動作」。
- **配角（只在角色一覽裡）**：`src/extras.mjs`
  - 校長：「72」低面數男生模型＋白髮、白鬍子、紫金長袍。
  - 副校長：西里爾的模型改高、深色頭髮夾灰白、黑銀長袍（父子長得像）。
  - 舍監赫爾嘉：月晞的臉，換上艾洛拉模型的短捲髮（灰白）和眼鏡。
  - 魔藥學教授薇拉：艾洛拉的臉，換上月晞模型的頭髮（深紅棕）。
  - 換髮型的程式在 `src/hairbank.mjs`：把 Character Creator 模型的頭髮、眼鏡拆下來，依眼距換算大小，戴到別人頭上。
  - 背景學生：「72」男生、女性人體雛形（沒有五官，所以戴兜帽，臉塗暗藏在陰影裡），換學院色就能變出很多人。
- **法杖**：右上角按鈕切換。星月法杖（女生，原檔 150 萬個頂點減到約 4 萬個三角形）、龍首法杖（男生，AI 生成模型，貼圖沒附，用程式依高度上色）。放在第一人稱畫面右下角，施咒時舉起並發出咒語的顏色。
- **角色風格比較**：右上「艾洛拉」鈕切換寫實模型和「程式繪製」的卡通版（`src/character.mjs`）。網址加 `?char=code` 預設程式繪製。

## 已知限制
- 在開發環境裡沒有顯示卡、也連不到 Supabase，所以「揮動手機」的靈敏度和「QR code 配對」**還沒在真的手機上測過**，需要製作人實測。
- 寫實模型沒有骨架：不能走路、沒有表情、嘴巴不會動，只會呼吸般微動並轉身面向玩家。要動起來需要綁骨架（例如 Mixamo 自動綁定）。
- 男性模型（Male_Human）的貼圖不在上傳的檔案裡；學士帽（AcademicCap）只有 Unreal／Blender 格式，這次沒有用到。
- 主角模型很細（各約 15～20 萬個頂點，艾洛拉的檔案 20 MB），教室裡同時有五個角色，舊手機可能會卡、下載也久。要再減量，最好在 Blender 裡做。
- 「72」男生模型面數很低，眼睛沒辦法畫出瞳孔，近看是空白的；比較適合遠看的背景人物。
- 撞臉：校長和男學生、赫爾嘉和月晞、薇拉和艾洛拉是同一張臉，用換髮型（和眼鏡）讓玩家看不出來。
- 配角（老師、背景學生、西里爾）還是穿程式做的筒狀斗篷；它們沒有骨架或是不同的身體，衣服還沒套上。
