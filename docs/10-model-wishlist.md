# 3D 模型清單（2026-10-22）

場景裡的家具、擺設現在都是程式用方塊、圓柱拼出來的（`game/src/art/dress.mjs`、`props.mjs`）。
有真的模型就能換上去，畫面會好很多。製作人下載後直接附在聊天裡給帳號二就好。

## 下載時請注意
- **格式**：選 **glTF / GLB**（`.glb` 最好）。`.usdz`、`.blend`、`.max` 網頁用不了（`.fbx`、`.obj` 可以但比較麻煩）。
- **大小**：一個模型 **5MB 以下**最好；有選項時選 **1K 貼圖**（不要 4K、8K）、**low poly**。
- **授權**：選 **CC0**（不用標註）或 **CC BY**（要標註作者，下載時記下網址）。
- **推薦網站**：
  - Poly Haven（polyhaven.com/models）：全部 CC0、品質很好，下載時選 glTF＋1K
  - Sketchfab（sketchfab.com）：搜尋後勾「Downloadable」，授權選 CC0 或 CC BY，格式選 glTF
  - Quaternius（quaternius.com）、Kenney（kenney.nl）：CC0、低多邊形
